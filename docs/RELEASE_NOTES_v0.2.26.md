# Invenqor Server·Agent v0.2.26 릴리즈 노트

릴리즈 일자: 2026-09-05
호환 Agent: v0.2.26 (Linux·Windows)

이번 릴리즈는 결함 하나를 고칩니다. 자리는 **Server가 조회 결과를 읽어 들이는
반복문 아홉 곳**이고, 증상은 이전 릴리즈들과 같은 종류 — **오류 없이 돌아온 뒤
조용히 짧아진 목록** — 입니다. 다만 이번에는 특정 질의가 아니라, 데이터베이스
연결이 도중에 끊어졌을 때 **어떤 목록이든** 그렇게 될 수 있었습니다.

## 1. 중간에 실패한 행 읽기가 완전한 결과로 응답됐습니다

`*sql.Rows` 반복문은 서로 다른 두 가지 이유로 멈춥니다. 결과를 끝까지 읽었거나,
읽는 도중에 실패했거나 — 연결이 끊어졌거나, 서버가 statement를 취소했거나, 값을
디코딩하지 못했거나 — 입니다. **`Next()`는 두 경우 모두 `false`를 돌려주므로
반복문 자체는 둘을 구분하지 못합니다.** 구분해 주는 것은 `rows.Err()` 하나뿐인데,
아홉 곳이 그것을 호출하지 않았습니다. 그래서 그때까지 도착한 행이 그대로 답이
되어 **HTTP 200**으로 나갔고, 그것이 결과의 조각이라는 표시는 응답 어디에도
없었습니다.

무엇을 잃는지는 엔드포인트마다 다릅니다.

- **`/api/v1/query/execute`** — 운영자가 판단의 근거로 삼는 자리입니다. 3,000대
  규모의 질의가 3대만 돌려줄 수 있었고, 바로 다음 줄에서 기록되는 감사 레코드는
  **그 짧아진 수를 "표현식에 일치한 자산 수"로 남겼습니다.**
- **Agent 목록**(`/api/v1/agents`), **설정 목록과 변경 이력**, 자산 하나의
  **수집 원천·변경 이력·관계** 목록이 모두 같은 모양이었습니다.
- **자산 병합**(`mergeAssets`)은 짧아지는 것보다 나빴습니다. scan 오류까지 버리고
  있어서, 실패한 scan이 **빈 문자열**을 "이번 병합이 옮긴 source id" 목록에
  덧붙였고 그 목록은 `asset_changes`에 **영구 기록**으로 들어갑니다.

이제 이 아홉 곳은 모두 반복이 실패로 끝난 경우 조각을 답으로 삼지 않고 요청을
실패시킵니다. 진단 로그 pruner만 예외적으로 읽어 온 행은 유지하되 그 회차를
"한 바퀴 돈 것"으로 치지 않고 버리며, 다음 회차가 목록을 다시 읽습니다.

## 2. 같은 실수를 다시 하지 못하도록 규칙을 테스트로 고정했습니다

나머지 행 반복문은 이미 `rows.Err()`를 확인하고 있었고 이 아홉 곳만 하지 않았는데,
이것은 핸들러를 하나씩 읽는 리뷰로는 잡히지 않는 종류의 차이입니다. 그래서
**Server 트리의 모든 행 반복문을 읽어**, 커서를 연 함수가 그 커서의 오류를
확인하는지 요구하는 테스트를 추가했습니다. CSV 컬럼이 `spreadsheetSafe`를 거치는지
소스를 읽어 검사하는 기존 테스트와 같은 방식입니다.

## 검증

- **규칙 자체를 테스트로.** 새 테스트는 수정 전에 아홉 곳을 파일·함수·변수 이름과
  함께 나열하며 실패하고, 수정 후 통과합니다. 반복문을 하나도 찾지 못하면 테스트가
  아무것도 증명하지 못하므로 그 경우에도 실패합니다.
- **두 저장 모드에서.** `go test ./...`이 SQLite fallback과
  `scripts/test-postgres.sh`의 실제 PostgreSQL 양쪽에서 전 패키지를 통과하고,
  `go vet`·`go build`·`gofmt`가 통과합니다.
- 콘솔은 `npm test`와 `npm run build`, 공개 계약은
  `redocly lint openapi.yaml`이 통과합니다. Agent(Rust)와 콘솔 코드는 이번
  릴리즈에서 바뀌지 않았습니다.

## 호환성

- 데이터베이스 마이그레이션이 없습니다.
- API 응답 형식 변경이 없습니다.
- **동작이 달라집니다.** 조회 도중 데이터베이스 읽기가 실패하면 해당 요청이
  이전처럼 부분 목록과 함께 200을 돌려주지 않고 **500 `INTERNAL_ERROR`**로
  끝납니다. 정상 경로에서는 아무것도 달라지지 않습니다.
